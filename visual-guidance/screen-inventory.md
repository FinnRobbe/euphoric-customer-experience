# Screen inventory

Three reference frames of the current Benefits+ / Navigator UI.

## 01 — Benefit detail: Private Medical Insurance

`references/01-benefit-detail-pmi.png`

- **Route context:** Benefit detail under Benefits → Private Medical Insurance (AXA Health).
- **Chrome:** Persistent left app shell (logo, Search or ask, nav, user).
- **Page header band:** Soft lavender/lilac full-width wash behind breadcrumb + provider mark + title.
- **Body:** White canvas with:
  - **Overview** card (long-form benefit copy).
  - **Included features** preview row (2+ feature cards) + **See all**.
  - Right rail **Plan information** card with **Manage benefit** (external-link treatment).

## 02 — Benefits catalog: Insurance filter

`references/02-benefits-insurance-grid.png`

- **Route context:** Benefits index, segment **Benefits**, chip **Insurance**.
- **Chrome:** Same left shell.
- **Top controls:** Segmented count tabs (Benefits / Explore / External) + icon filter chips (All, Insurance, Non-insurance, Company-delivered).
- **Content:** Section title **Insurance (n)** + multi-column **benefit cards** (provider-colored header blocks, logos, optional feature-count badge, provider label, title, truncated description).

## 03 — Included features modal

`references/03-included-features-modal.png`

- **Context:** Opened from PMI detail **See all** (or equivalent).
- **Pattern:** Large centered white modal over dimmed detail page; title **Included features** + close (X).
- **Content:** Dense **3-column grid** of feature cards (provider logo, save heart, title, short description). Hover/focus shown as stronger border/shadow on one card.
