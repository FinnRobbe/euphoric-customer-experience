# Rubric — navigator-fit

Score each: **pass** / **partial** / **fail**.

| Dimension | Pass looks like |
|---|---|
| Shell | App chrome matches Navigator / visual-guidance employee product, not a spreadsheet |
| Cards & wash | Benefit cards, logos, wash colours feel consumer-grade |
| Typography / density | Calm, readable; not admin-dense tables everywhere (tables OK if purposeful) |
| White-label cues | Prototype can be framed as employer-branded Navigator without contradiction |
| Consistency | Detail / Personalise / Compare share one visual language |
