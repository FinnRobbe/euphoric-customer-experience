# Rubric — money-honesty

Score each: **pass** / **partial** / **fail**.

| Dimension | Pass looks like |
|---|---|
| You pay label | Employee cash uses dictionary **You pay** consistently on sticky/rail surfaces |
| Employer funding | Employer contribution toward core is shown without folding BIK into cash |
| Est. tax / BIK | Benefit-in-Kind / Est. tax is separate and explained |
| Draft vs applied | Current price / New price (or equivalent) make draft state obvious |
| Prototype honesty | Illustrative / prototype disclaimers present where money is shown |
| No invented cover | Costs don’t invent benefits or hide material excess implications |
