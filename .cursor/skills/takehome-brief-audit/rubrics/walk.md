# Rubric — walkability

Score each: **pass** / **partial** / **fail**.

| Dimension | Pass looks like |
|---|---|
| Happy path | Grid → enrolled PMI → Personalise → change something → Apply story completes |
| Hard path | Dependant overflow and/or insurer switch has a clear narrative (even if blocked) |
| Compare path | Compare is useful or honestly limited; doesn’t strand “selected” state |
| Feature depth | Opening a feature detail doesn’t break the personalise story |
| Recovery | Leave-without-saving / discard / back links behave predictably |
| Scriptability | You could write a 10-bullet interview script without “ignore this screen” |
