# Rubric — ux-simplicity

Score each: **pass** / **partial** / **fail**.

| Dimension | Pass looks like |
|---|---|
| Time to first value | Employee understands current cover and next action within ~30s on detail/Personalise |
| Decision load | Personalise doesn’t force simultaneous mastery of matrix + household + extras + legal |
| Enrolled vs browse | Switch modelling is visually/verbally distinct from managing enrolled cover |
| Dead ends | Primary CTAs either work or explain why disabled; no silent traps |
| Hierarchy | One primary action per key screen; secondary actions don’t compete equally |
| Mobile / narrow | Critical rail/actions remain usable (or gracefully stack) |
