# Rubric — ai-native

Score each: **pass** / **partial** / **fail**.

| Dimension | Pass looks like |
|---|---|
| Guidance surface | Employee can ask / receive plan-aware help (even if prototype/canned) |
| Personalisation intelligence | Fit / mismatch / recommendation logic affects the journey (not decoration) |
| Flex co-pilot | AI/guidance helps with cover, dependants, extras, or switch tradeoffs |
| Honesty about AI | Canned vs live is clear; doesn’t overclaim “AI” without a demoable behaviour |
| Interview story | You can point to 2–3 moments and say “this is the AI-native part” without embarrassment |
