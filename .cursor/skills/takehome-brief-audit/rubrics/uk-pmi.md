# Rubric — uk-pmi-flex

Score each: **pass** / **partial** / **fail**.

| Dimension | Pass looks like |
|---|---|
| Cover levels | Distinct tiers with meaningful excess / outpatient / hospital / cancer differences |
| Dependants | Partner/children rules, caps, overflow handling; honest “can’t fit” messaging |
| Optional extras | Paid add-ons with clear employee cost; not confused with core cover |
| Contribution tradeoffs | You pay / employer funding / plan change deltas are visible before Apply |
| UK realism | Excess, pre-authorisation, day-case, BIK language don’t invent US HSA-style flex |
| Multi-provider | AXA / Bupa / Vitality differences are usable, not cosmetic clones only |
